# PROJECT: Sachin Sharma - AI & Agentic Systems Engineer Portfolio

## Vision & Objective
Build a high-performance, aesthetically refined, ATS/Recruiter-optimized AI Engineer portfolio website. The portfolio rejects slow generic 3D fluff and instead implements the "Modern AI Lab / Infrastructure" aesthetic (Linear/Vercel/OpenAI style) with an interactive 3D Semantic Vector Space visualizer, deep-dive architectural case studies for flagship projects (AutoApply & VideoSage AI), live interactive evaluation/RAG playground, structured technical taxonomy, and direct recruiter CTAs.

## Core Audience
- AI Engineering Hiring Managers & Tech Leads
- AI/ML Technical Recruiters & Sourcers
- Open-source Collaborators

## Key Requirements & Guarantees
- Sub-second load time, zero WebGL lag, 100% responsive on mobile and desktop.
- Domain-relevant 3D: Interactive 3D vector embedding cluster visualizer showing cosine distance & semantic clustering.
- Case study deep dives with interactive architecture flow charts and hard-metric impact.
- Interactive RAG vs. Naive Retrieval & Eval benchmarks simulator.
- Easy to customize, redesign, and extend.

## Location & Environment
- Workspace & Dependencies: `D:\ai-portfolio`
- Stack: React 19, Vite, Tailwind CSS v4, Three.js, Lucide Icons
