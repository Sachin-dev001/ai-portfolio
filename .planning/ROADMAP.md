# GSD ROADMAP: Redesign to Award-Winning 3D Luxury AI Portfolio

## Goal
Completely replace the generic "AI-slop" look (neon purple/blue gradients, flat cards) with an Awwwards-grade, minimal-luxury, high-end 3D developer portfolio.

## Phase 1: Brand & Design Language Reset (Unslop & Luxury Redefinition)
- [x] Web research on Awwwards-winning 3D portfolios (Bruno Simon, Minimal Luxury AI, Apple Pro style).
- [ ] Color Palette: Pure Obsidian (`#060709`), Titanium (`#e4e4e7`), Graphite (`#111216`), Hairline borders (`rgba(255,255,255,0.06)`). Remove all purple/blue glowing washes.
- [ ] Typography: Editorial Plus Jakarta Sans / JetBrains Mono pairing with tight tracking and refined letter-spacing.

## Phase 2: Bespoke 3D Interactive Canvas (The Hero Experience)
- [ ] Build a multi-mode 3D interactive WebGL canvas (Neural Lattice Core, Latent Space Particles, Synaptic Knowledge Graph).
- [ ] Mouse gravity, fluid vertex ripple physics, camera parallax, and real-time interactive mode toggles.
- [ ] 60+ FPS high-performance render loop with adaptive pixel ratio and zero frame drops.

## Phase 3: Project Showcases with 3D Parallax & Live Terminal Simulator
- [ ] 3D perspective hover cards with cursor-following specular sheen.
- [ ] Live interactive CLI / Terminal console: recruiters can click to run agent tasks (`autoapply --stealth` / `videosage --rerank`) and watch live streaming telemetry.
- [ ] Architectural data flow blueprints with animated SVG pulses.

## Phase 4: Interactive Model Latency & Rerank Benchmark Lab
- [ ] Redesign the interactive playground to look like a high-end AI research instrument (Linear/OpenAI evals bench).
- [ ] Live latency, precision lift, and context recall dials.

## Phase 5: Floating Island Dock, Resume Vault & Refined Verification
